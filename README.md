### 2. Line-Follower Competition Robot

**Microcontroller · 8-Channel Sensor Array · PD Control · Motor Control · Real-Time Embedded Programming**

My first embedded vehicle project. I assembled and integrated the hardware, developed the line-following control software, and initially tested the vehicle on a figure-eight track at Ton Duc Thang University. The platform was later further tuned and used in competition in Binh Duong, where it achieved **Second Prize**.

Technical work includes sensor calibration, weighted line-position estimation, PD steering correction, differential motor control, Timer2 interrupt-based sampling, line-loss recovery, and sharp-turn handling.

[**View Repository**](https://github.com/TuanDo1704/line-follower-robot) · [**Project Materials**](https://drive.google.com/drive/folders/1qVUNdeQNl_YnuXo2LCKvLRSYQyKm8aJk?usp=sharing)

### 3. Hydrogel Morse Decoder

**ESP32 · ADS1115 · Hydrogel Strain Sensor · Signal Acquisition · Gesture Detection · Morse Decoding**

Embedded sensing project that converts hydrogel resistance changes caused by finger flexion into Morse-code symbols and decoded alphabet characters.

The implementation combines high-resolution analog acquisition, resistance estimation, trimmed-sample filtering, EMA filtering, adaptive baseline calibration, hysteresis-based gesture detection, flex-duration classification, and embedded Morse decoding.

[**View Repository**](https://github.com/TuanDo1704/morse-code) · [**Project Materials**](https://drive.google.com/drive/u/0/folders/1AI34_kE8Ka_XqHm_iiQjXMtUHJEGeXEZ)
